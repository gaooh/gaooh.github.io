プライバシーポリシー

最終更新日: 2026年9月2日

本ポリシーは、個人用ツール「Leonis」（以下「本アプリ」）における ユーザーデータの取り扱いを定めるものです。 本アプリは開発者本人が自身のデータを管理するために作成した個人用ツールであり、 利用者は開発者 1 名のみです。第三者への提供・配布は行っていません。

1. 取得する情報

本アプリは、利用者本人が明示的に許可した場合にのみ、以下の Google ユーザーデータへアクセスします。

  • Google Drive（.../auth/drive）
    利用者が指定した単一のフォルダ（食事写真の受け渡し用 inbox）配下にある画像ファイル、 およびその名称・作成日時・チェックサム等のメタデータ。 取り込み完了後、当該ファイルをゴミ箱へ移動します。 ファイルの完全削除およびゴミ箱の空にする操作は一切行いません。 指定フォルダ以外のファイルにはアクセスしません。
  • Google Health（栄養ログ） （.../auth/googlehealth.nutrition.readonly、 .../auth/googlehealth.nutrition.writeonly）
    利用者本人の食事・栄養に関する記録。

2. 利用目的

取得した情報は、利用者本人の健康記録を手元に集約し、日次のノートとして整理する目的にのみ使用します。 これ以外の目的には使用しません。

3. 保存場所と保存期間

  • 取得したデータおよび認証トークンは、開発者所有の Mac のローカルストレージにのみ保存されます。
  • 本アプリはサーバーを持たず、外部のホスティング環境へデータを送信しません。
  • 認証トークンは本人のみが読み取れる権限（600）で保存されます。
  • 保存期間の定めはなく、利用者本人が任意に削除できます。

4. 第三者提供

取得した情報を第三者へ提供、販売、譲渡、貸与することはありません。 広告・分析・機械学習モデルの学習を含む、いかなる二次利用も行いません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）を遵守します。

6. アクセス権の取り消し

利用者はいつでも Google アカウントの権限設定 から本アプリのアクセス権を取り消せます。取り消し後、本アプリは Google 上のデータへアクセスできなくなります。 ローカルに保存済みのデータは、利用者本人が手元で削除できます。

7. 本ポリシーの変更

本ポリシーを変更する場合は、本ページの最終更新日を改めます。
